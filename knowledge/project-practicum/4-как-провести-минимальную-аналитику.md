# Как провести минимальную аналитику ​

В этом разделе приведены **минимальные требования** к аналитике, самые базовые приёмы, которые необходимо провести.

## Обзор существующих решений ​

Первым делом вам нужно поискать аналоги:

- Через поисковик напрямую по кратким запросам. Рекомендуем также использовать английские варианты написания и поискать не только в российском пространстве.
- Через ИИ, которые поддерживают подключение к интернету. Это могут быть DeepSeek, Qwen, Perplexity и другие. - Поиск через поиск **решения проблемы.** Опишите LLM проблему, которые вы хотите решить и спросите варианты, как это можно сделать, есть ли существующие решения / open source проекты или какая-то комбинация продуктов для решения данной проблемы/задачи. Чаще всего уже есть существующие аналоги или полностью покрывающие ваш запрос решения.
- Поиск прямо **через описание идеи сервиса / продукта** и т.д. Данный подход хуже, так как фокусирует на конкретном решении, которое может быть не оптимальным, если у вас нет достаточной насмотренности в области и эрудиции.

Когда найдены аналоги / варианты решения проблемы / готовы решения, то можете сделать следующий шаг - попробовать ими попользоваться. Это позволит с одной стороны проверить, что действительно эти решения пригодны, с другой стороны возможно найти их недостатки. Главное - рассмотреть минимум 4-5 вариантов, только так у вас появится некоторая насмотренность, и вы увидите недостатки решений / хорошие ходы / удобные приёмы интерфейса. **Текстовый обзор через LLM и чужие обзоры не даст этого эффекта - он бесполезен.**
