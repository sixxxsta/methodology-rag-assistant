# Роль: студент-участник ​

Роль существует в рамках проектной деятельности внутри команды проекта. В данной роли могут выступать только студенты университета бакалавриата и магистратуры.

- **Что ожидается от роли (обязательное):**

- Вклад в командную работу на **всех стадиях работы**
- Коммуникация с другими участниками процесса: сокомандники, кураторы, организаторы, заказчики, эксперты
- Участие в защитах и презентация личного прогресса
- Работа над проектом **не менее** 5 часов в неделю на 1-2 курсе, и **не менее** 7 часов в неделю на 3-4 курсе

- **Что ожидается от роли (желательное):**

- Постановка личных целей на семестр
- Решение нехватки компетенций/ресурсов через коммуникацию и взаимодействие с другими участниками
- Самостоятельное развитие в рамках своей роли и функциональных задач

- **Чего НЕ ожидается:**

- Одиночная индивидуальная работа без команды
- Владение всеми навыками во всех ролях
- Работы исключительно по инструкции

- **Типичные взаимодействия**:

- С другими студентами-участниками для работы над проектом
- С заказчиком/партнёром для создания полезного продукта
- С куратором/наставником для отчетности и консультаций
- С экспертами для получения советов/консультаций
- С организаторами, чтобы получить информации и сообщить о проблемах

- **Жизненный цикл роли**

- Не записан → записан в команду → записан на проект → работает → прошёл защиту (→ возможно: выбыл, сменил команду).

**Может быть случай, когда студент сначала записан на проект, а только потом ему помогают записаться в команду. Эта специфика обычно обозначается в описании проекта.*
