# Минимальные условия зачёта по преддипломной практике ​

Преддипломная практика содержательно связана с вашей ВКР, но в учебном плане остаётся **отдельной учебной активностью**. Поэтому для её зачёта важно не только продвигаться по теме и показывать результат, но и выполнить **минимальные обязательные условия** по комплекту материалов и по содержательной готовности работы.

Зачёт по практике ставится не по общему впечатлению, а при выполнении **всех обязательных условий**, перечисленных ниже. Если хотя бы одно из них не выполнено, практика не считается зачтённой.

## Когда практика считается зачтённой ​

Преддипломная практика считается зачтённой, если одновременно выполнены два условия:

- **Сданы все обязательные материалы**, перечисленные в таблице выше.
- **По содержательным критериям набрано не менее 40%** от максимального количества баллов по оценочному листу.
Если хотя бы одно из этих условий не выполнено, практика считается незачтённой.

## Что означает пункт про содержательные критерии ​

Содержательная часть практики оценивается не как отдельная, полностью изолированная работа, а через **общую логику вашего прогресса по ВКР**. Это означает, что при оценке учитывается, насколько вы продвинулись по теме, насколько понятна логика вашей работы, что именно уже сделано и насколько это подтверждено материалами.

Для зачёта по практике используется **минимальный порог готовности** — не менее 40% от максимума по оценочному листу. Это означает, что на данном этапе от вас не требуется полная готовность всей ВКР, но должен быть подтверждён реальный и достаточный прогресс по теме.

## Что важно помнить ​

Для зачёта по практике недостаточно только подготовить документы. Также недостаточно только показать содержательный прогресс без полного комплекта материалов. Для успешной сдачи практики нужно одновременно:

- подготовить и сдать все обязательные документы;
- показать минимально необходимый уровень содержательной готовности работы.
