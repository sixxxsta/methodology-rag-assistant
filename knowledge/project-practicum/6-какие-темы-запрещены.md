# Какие темы запрещены ​

Запрещены к разработке на практикуме:

- Социальные сети в любом виде: про путешествия, знакомства, тематические по интересам, по видам спорта, про животных и т.д.
- Сервисы поиска сокомандников для практикума / грантов / проектов и т.д.
- Интернет магазины без наличия заказчика или самостоятельного бизнеса у команды
- Сервисы по поиску домашних животных / предметов / ...
- Агрегаторы информации для студентов по учебному процессу в УрФУ
- Агрегаторы городских мероприятий
- Прямые копии существующих приложений и сервисов, либо которые заменяются существующими аналогами. Например, создание сервиса для работы с RAG и ИИ, когда уже создан n8n.
Данные сервисы можно реализовывать при условии, что команда имеет заказчика/ гарантийное письмо о сотрудничестве / грант в рамках которого делают проект или заказчика, который уже платит за это деньги.
