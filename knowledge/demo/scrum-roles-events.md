# Scrum: роли, события, артефакты

## Роли

| Роль | Ответственность |
|------|-----------------|
| **Product Owner** | Приоритеты, ценность для пользователя, приёмка |
| **Scrum Master** | Процесс, препятствия, фасилитация |
| **Команда разработки** | Поставка инкремента продукта |

В учебном проекте роли можно совмещать, но **ответственность** должна быть явной.

## События (календарь на спринт 2 недели)

1. **Планирование спринта** (2–4 ч) — цель спринта, backlog спринта.
2. **Daily Scrum** (15 мин) — синхронизация: вчера / сегодня / блокеры.
3. **Обзор спринта** — демо инкремента стейкхолдерам.
4. **Ретроспектива** — что улучшить в процессе.

## Артефакты

- **Product Backlog** — упорядоченный список всего, что нужно продукту.
- **Sprint Backlog** — задачи текущего спринта.
- **Инкремент** — готовая часть продукта, соответствующая Definition of Done.

## Definition of Done (пример для IT-проекта)

- Код в репозитории, проходит review.
- Есть тесты или проверка сценария.
- Обновлена пользовательская/техническая документация.
- Демонстрируется на стенде или локально.
