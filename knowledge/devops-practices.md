# DevOps-практики для студенческих проектов

## Культура

DevOps — это сотрудничество разработки и эксплуатации (в учебном проекте — «кто деплоит и поддерживает»).

## Базовый набор

1. **Система контроля версий** (Git), ветвление по feature.
2. **CI** — автоматическая сборка и тесты на каждый push.
3. **Контейнеризация** (Docker) для воспроизводимого окружения.
4. **Инфраструктура как код** — docker-compose, README с командами запуска.
5. **Мониторинг** — health-check эндпоинты, логи.

## Pipeline (минимум)

```
commit → build → test → (optional) deploy to staging
```

## Безопасность

- Секреты только в `.env`, не в репозитории.
- `.env.example` без реальных ключей.
- Ротация токенов API (GigaChat, Qdrant cloud).
