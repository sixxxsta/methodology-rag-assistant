# База знаний для RAG

Ассистент отвечает **только на основе** файлов из этой папки (рекурсивно, включая подпапки).

## Основной источник: Проектный практикум УрФУ

Папка `project-practicum/` — **54 страницы** базы знаний [Проектный практикум | Студентам](https://xn--d1acynfdde.xn--e1aajagmjdbheh6azd.xn--p1ai/).

| Раздел | Содержание |
|--------|------------|
| Проекты студенческой инициативы (ПСИ) | заявки, отбор, аналитика, запрещённые темы |
| Первый курс, весна 2026 | этапы семестра, куратор, КТ, отчёт, защита |
| Старшие курсы 2–3 | выбор проекта, КТ, защита |
| Общая информация | советы и лайфхаки |
| Преддипломная практика / ВКР | документы, структура ВКР, зачёт |
| Заочники | формат работы и запись на проект |

В начале каждого файла есть комментарий `<!-- source: URL -->` с оригинальной ссылкой.

## Обновление базы с сайта

Скрипт и список URL лежат в корне рабочей папки (рядом с репозиторием):

- `scrape_kb_urls.py` — загрузка страниц VitePress в Markdown
- `kb_urls.txt` — список URL для импорта

```bash
python scrape_kb_urls.py
```

## Индексация в RAG

После добавления или изменения файлов:

```bash
curl -X POST http://localhost:8100/ingest
```

Или перезапустите сервис `rag` при пустой коллекции Qdrant (`AUTO_INGEST_ON_STARTUP=true`).

Если в индексе остались старые чанки, перед повторной индексацией очистите коллекцию Qdrant или пересоздайте volume.
