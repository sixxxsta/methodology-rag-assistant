# База знаний для RAG

Ассистент отвечает **только на основе** файлов из этой папки. Чем качественнее материалы, тем точнее ответы.

## Какие файлы класть

| Формат | Поддержка |
|--------|-----------|
| `.md` | да |
| `.txt` | да |
| `.pdf`, `.docx` | нет (сначала конвертируйте в Markdown) |

Кодировка: **UTF-8**.

## Что включать (рекомендуемые темы)

1. **Agile / гибкие методологии** — манифест, принципы, итерации  
2. **Scrum** — роли, события, артефакты, Definition of Done  
3. **Kanban** — WIP, поток, метрики  
4. **Планирование** — спринт, оценка, риски, DoR  
5. **Команда** — RACI, роли, коммуникации  
6. **DevOps** — CI/CD, Docker, мониторинг, секреты  
7. **Документация** — ГОСТ 19 / ЕСПД (краткие выжимки, не полные сканы)  
8. **Ваши регламенты** — правила курса, шаблоны отчётов, чек-листы защиты  

## Как оформлять документы

- Один файл — одна тема (`scrum-roles.md`, `sprint-planning.md`).  
- Заголовки `#`, `##` — так chunker лучше режет текст.  
- Короткие абзацы, списки, таблицы — удобнее для поиска.  
- Указывайте **конкретику**: примеры для студенческих команд, не общие фразы.  
- Не дублируйте одно и то же в десяти файлах — размывает релевантность.  

## Чего избегать

- Слитые «простыни» на 50+ страниц без структуры  
- Устаревшие или непроверенные советы  
- Сканированные PDF без OCR  
- Секреты, персональные данные, ключи API  

## Как загрузить в систему

**Автоматически** — при первом старте RAG, если коллекция Qdrant пуста (`AUTO_INGEST_ON_STARTUP=true`).

**Вручную** — после добавления файлов:

```bash
curl -X POST http://localhost:8100/ingest
```

или перезапуск контейнера `rag` (при пустой коллекции снова сработает auto-ingest).

## Объём

Для учебного проекта достаточно **10–30** статей по 1–5 страниц. Больше — лучше recall, но дольше первая индексация.
